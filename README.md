# Blood Strike Aim Panel — protótipo Android

Este é um protótipo de treinamento local em Kotlin/Jetpack Compose. O rastreamento demonstrativo move uma mira em direção a um alvo animado **dentro da própria tela do aplicativo**.

Não se conecta ao Blood Strike, não lê/modifica memória de outros apps e não automatiza entradas no jogo.

## Abrir e gerar APK
1. Extraia o ZIP.
2. Abra a pasta `BloodStrikeAimPanel` no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Use **Build > Build APK(s)**.
5. O APK de depuração será gerado em `app/build/outputs/apk/debug/`.

Configuração: minSdk 23, compileSdk 35, Kotlin + Jetpack Compose.
